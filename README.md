# ShopManagement

## Project Description
ShopManagement is an offline mobile application designed to help small shop owners manage their daily business activities. It supports stock management, sales tracking, expense recording, and profit calculation.

## Features
- User Registration and Login
- Dashboard with Business Summary
- Stock Management (Add, Update, Delete)
- Low Stock and Out-of-Stock Alerts
- Sales Management and Sales History
- Expense Management
- Profit Calculation and Reports
- Database Backup and Restore
- Shop Information and Account Management
- Theme Settings
- Offline Data Storage

## Technologies Used
- **React Native** - Mobile App Development
- **Expo** - Development Framework
- **JavaScript** - Programming Language
- **SQLite** - Local Database
- **React Navigation** - Screen Navigation
- **Expo FileSystem** - File Management
- **Expo Sharing** - Database Backup Sharing
- **Git and GitHub** - Version Control

## Setup Instructions

  ### For Users
1. Install the ShopManagement application on your Android.

## Download App

Scan the QR code to download the ShopManagement app.

![ShopManagement QR Code](assets/qr-code.jpeg)


2. Open the application.
3. Create a new account using the registration screen.
4. Log in with your account details.
5. Enter your shop information.
6. Add products with quantities, purchase costs, and selling prices.
7. Start recording sales and expenses.
8. View business summaries and profits on the Dashboard.
9. Use the Backup and Restore feature to protect your data.


  ### Offline Usage
The application stores business data locally using SQLite. An internet connection is not required for normal stock, sales, expense, and reporting operations.
